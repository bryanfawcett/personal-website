# Content Signals
#
# A stated preference about how automated systems may use what is on this site.
# The three signals mean, per the Content Signals Policy (contentsignals.org):
#
#   search    building a search index, and showing links back to the source
#   ai-input  feeding the content to an AI model to help generate a response,
#             the way an assistant cites a page it has just read
#   ai-train  training or fine-tuning a model on the content
#
# Search and AI answers are welcome: both send readers back here. Training is
# not, because it takes the writing without attribution or a route back.
#
# This is a declaration, not a lock. It relies on the crawler honouring it —
# enforcement is a Cloudflare dashboard setting, not a line in this file.

User-agent: *
Content-Signal: search=yes, ai-input=yes, ai-train=no
Allow: /
