A strip of captioned plates from the workshop, each framed like the portrait.

**You provide** the language; the plates and captions come from the site's data.

**Variants**

| Variant | Use when |
|---|---|
| Strip | Under the hero, to show the work. |

**States**

| State | How it looks and behaves |
|---|---|
| Default | Plates in a row with mono captions. |
| Hover / focus / disabled | Not interactive. |

**Accessibility.** Each plate's caption is its accessible name.

**Do.** Keep captions to a label.

**Don't.** Make the plates a carousel.

**Tokens.** `ink`, `ink-hair`, `label`, `radius-lg`.
